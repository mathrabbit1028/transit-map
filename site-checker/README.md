# site-checker

지도에서 클릭한 지점을 **이름/위도/경도**와 함께 등록하고, 규칙 기반 **고유번호(SSNNN)** 를 생성해 저장하는 간단한 GUI입니다.

- **SS**: 등록 세션(1~99) → 2자리
- **NNN**: 같은 세션 내 순번(1~999) → 3자리

예: 세션이 3이고 그 세션의 12번째 등록이면 `03012`

## 실행 방법

이 프로젝트는 **세션별 JSON 파일을 읽고/쓰기** 하기 위해 로컬 서버가 필요합니다.

`data/position/01.json` 같은 파일을 **자동으로 읽고/저장**하려면 Node 서버를 실행하세요.

```bash
npm install
npm run dev
```

그 다음 브라우저에서 `http://localhost:5173` 로 접속합니다.

## 데이터 저장

등록 데이터는 세션 번호(앞 2자리) 기준으로 아래에 저장됩니다.

- `data/position/01.json`
- `data/position/02.json`
- ...

GUI에서 세션 번호를 바꾸면 해당 JSON을 자동으로 로드해서 띄우고,
등록/삭제/전체삭제 시 자동 저장합니다(세션 변경 직전에도 저장).

- **JSON 내보내기**: 현재 포인트 배열을 JSON으로 확인/복사
- **전체 삭제**: localStorage 데이터 초기화

## 데이터 형식

```json
{
  "id": "03012",
  "session": 3,
  "seq": 12,
  "name": "시청역 1번 출구",
  "lat": 37.5665,
  "lng": 126.978,
  "createdAt": "2026-02-21T12:34:56.000Z"
}
```
